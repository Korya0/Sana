description: Phase 1 - Deep architectural analysis and alternatives comparison.
---

1. Verify the current git branch and report it to the user.
2. Analyze the user's mission from a Senior Architect perspective.
3. Propose **3 Alternatives**:
   - **Approach A (Minimalist)**: Quickest path, low complexity.
   - **Approach B (Scalable)**: Balanced for growth and maintenance.
   - **Approach C (Ultimate)**: Over-engineered or feature-rich for extreme robustness.
4. For each approach, provide:
   - **Pros**: Efficiency, Performance, Security.
   - **Cons**: Trade-offs, Tech Debt, Complexity.
5. Provide a **Matrix Comparison** (Complexity vs. Value).
6. **Wait for the user's decision** on which path to follow.
