# Main Layout Feature (الهيكل الرئيسي)

هذه الميزة توفر الغلاف الأساسي (Shell) للتطبيق، والذي يحتوي على شريط التنقل السفلي (Bottom Navigation Bar) وتوجيه الواجهات الرئيسية (Routing).

## 🏗 المعمارية والتصميم

1. **التنقل المتقدم (Stateful Navigation):**
   - تعتمد الميزة على `StatefulNavigationShell` من حزمة `go_router` للاحتفاظ بحالة الشاشات. مما يعني أن المستخدم إذا قام بالتمرير في شاشة "الرئيسية" ثم انتقل لـ "الإعدادات" وعاد، فسيجد الشاشة في نفس الموضع دون إعادة تحميل.

2. **التصميم التفاعلي والأيقونات (Aesthetics & Icons):**
   - تم استخدام `SolarIconsOutline` للتبويبات غير النشطة، و `SolarIconsBold` للتبويبات النشطة لتوفير إحساس (Premium) وتفاعل واضح للمستخدم عند التنقل.
   - يعتمد التصميم على نظام الألوان الموحد `context.color` من تصميم المشروع (Theme Extensions) ليتماشى بسلاسة مع الوضع الليلي/النهاري.

## 🚀 الاستخدام (Usage)
تعديل شريط التنقل أو إضافة تبويب جديد:
1. أضف الـ Route الخاص بالشاشة كفرع (Branch) داخل ملف `app_router.dart`.
2. قم بإضافة `BottomNavigationBarItem` جديد داخل `main_layout_view.dart` مع مراعاة استخدام الأيقونات (Outline/Bold) للحالة العادية والنشطة.
3. التزم بتجنب استخدام `Padding` فردي للعناصر واعتمد على الخصائص المدمجة في `BottomNavigationBar` لضمان التوافق.
