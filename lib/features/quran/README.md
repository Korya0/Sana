# 📖 مزية القرآن الكريم (quran)

## نظرة عامة

مزية `quran` توفر تجربة قراءة كاملة للمصحف الشريف داخل التطبيق. تعتمد هذه المزية على دمج مكتبة متخصصة (`quran_library`) مع تخصيصات بصرية تتناسب مع الهوية البصرية لتطبيق "سنا" (Sana)، مع دعم الوضع الليلي والألوان الذهبية المميزة.

---

## 📁 هيكل الملفات

```
quran/
└── presentation/
    └── views/
        └── quran_view.dart      ← الشاشة التي تعرض المصحف
```

---

## 🎨 التخصيص والتركيب

تم بناء شاشة `QuranView` لتكون بسيطة ولكن غنية بالتفاصيل البصرية:

### 🛠️ مكتبة `quran_library`
يتم استخدام هذه المكتبة لأنها توفر:
- صفحات المصحف (الرسم العثماني).
- الفهرس (سور، أجزاء).
- البحث في الآيات.
- علامات التوقف (Bookmarks).
- الاستماع للتلاوات.

### 🎨 التخصيصات الخاصة (Customization)
تم تزويد المكتبة بإعدادات خاصة لتناسب التطبيق:
- **الخلفية**: استخدام اللون الأسود الداكن (`#161a1d`) لتوفير راحة تامة للعين أثناء القراءة الطويلة.
- **تحديد الآيات**: الآية المختارة تظهر بخلفية ذهبية شفافة (`AppColors.gold.withOpacity(0.3)`).
- **العناوين (MetaData)**: تلوين أسماء السور، أرقام الصفحات، أسماء الأجزاء، وعلامات السجدة باللون الذهبي (`AppColors.gold`).
- **الأيقونات**: تحويل جميع أيقونات التفاعل (مثل أيقونة السجدة أو علامات الأجزاء) إلى اللون الذهبي الموحد للتطبيق.

---

## ⚙️ آلية التشغيل

بما أن مكتبة القرآن قد تحتاج وقتاً بسيطاً للتحميل الأول (قاعدة البيانات والخطوط)، تتبع الشاشة هذا الأسلوب:

```dart
FutureBuilder(
  future: _initFuture,
  builder: (context, snapshot) {
    if (snapshot.connectionState != ConnectionState.done) {
      // عرض شاشة تحميل سوداء مع شعار ذهبي دوار
      return const CircularProgressIndicator(color: AppColors.gold);
    }
    // عرض المكتبة فور اكتمال الجاهزية
    return QuranLibraryScreen(...);
  }
)
```

## 🔗 الارتباط بالمزايا الأخرى

- **`Home`**: يمكن الوصول للمصحف مباشرة من بطاقة القرآن في الشاشة الرئيسية.
- **`Theme`**: تلتزم الشاشة بالهوية البصرية (Gold & Dark) المحددة في النظام الأساسي للتطبيق.
