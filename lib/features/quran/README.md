# Quran Feature

## Overview
Comprehensive Quran viewing and management.

## Features
- **Uthman Taha Font**: Authentic Quran reading experience.
- **Bookmarks & Favorites**: Save progress and favorite verses.
- **Search**: Fast search in Quranic text.
- **Last Read**: Quick access to where you left off.

## Technical Details
- Uses `quran_library` for core data and rendering.
- State management via `QuranCubit`.
- UI optimized with `StatefulWidget` to prevent redundant initialization.
