# 🔄 App Update Feature

تعتبر ميزة **App Update** هي المسؤولية عن ضمان تشغيل المستخدم لأحدث نسخة من التطبيق، سواء عبر التحديث الإجباري (Force Update) أو التحديث الاختياري (Optional Update) من خلال **Firebase Remote Config**.

## 🚀 المميزات الرئيسية
- **التحديث الإجباري:** منع المستخدم من دخول التطبيق في حال وجود نسخة قديمة غير مدعومة، مع عرض رسالة مخصصة.
- **التحديث الاختياري:** عرض بانر جذاب في أسفل الشاشة الرئيسية لإبلاغ المستخدم بوجود تحديث جديد مع إمكانية إغلاقه.
- **إدارة الإصدارات:** مقارنة دقيقة لإصدار التطبيق الحالي مع الإصدار المستهدف من السيرفر.
- **التخزين المؤقت (Caching):** حفظ إعدادات البحث الأخيرة لضمان ظهور شاشة التحديث فوراً عند فتح التطبيق حتى في وضع عدم الاتصال.

## 🏗 الهيكل المعماري (SOLID Implementation)

### 1. Data Layer
- **Model:** `UpdateConfigModel` - يحدد بيانات التحديث (رقم الإصدار، نوع التحديث، الرابط، الرسالة).
- **Service:** `AppUpdateServiceImpl` - المسؤول عن التواصل مع Firebase Remote Config و SharedPreferences.
- **Repository:** `AppUpdateRepository` - واجهة تفصل المنطق عن المصادر الخارجية.

### 2. Logic Layer (Cubit)
- **AppUpdateCubit:** يدير عملية جلب البيانات وتحديث الـ UI. تم تصميمه بنظام الحالات المحمية (Manual Sealed Classes):
    - `AppUpdateInitial`: البداية.
    - `AppUpdateLoading`: أثناء جلب البيانات.
    - `AppUpdateSuccess`: تم التحميل بنجاح (سيتم فحص `isUpdateRequired`).
    - `AppUpdateFailure`: في حال وجود خطأ (يعتمد على البيانات المخزنة مؤقتاً).

### 3. Presentation Layer (UI)
- **Widgets:**
    - `UpdateOverlay`: المكون الرئيسي الذي يقرر ماذا يعرض بناءً على حالة التحديث.
    - `ForceUpdateOverlay`: شاشة كاملة تمنع التفاعل بفلتر ضبابي (Blur) وتجبر على التحديث.
    - `OptionalUpdateBanner`: بانر متحرك يظهر بمرونة في أسفل الشاشة.

## 🛠 أدوات مساعدة (Core Utilities)
- **VersionUtils:** فئة مستقلة تحتوي على منطق مقارنة الإصدارات (DIP)، مما يسهل اختبارها وعزلها عن الـ Cubit.

## 🎨 رموز التصميم (Design Tokens)
- **Spacing:** تعتمد الميزة بالكامل على نظام `AppSpacing` (v16, v24, v32).
- **Radius:** تستخدم `AppSpacing.radiusL` للبانرات و `radiusM` للأزرار.
- **Animations:** تستخدم `Curves.easeOutBack` لإعطاء شعور "Premium" عند ظهور البانر.

## 📝 ملاحظات للمطورين
- يتم جلب البيانات في خلفية التطبيق لضمان عدم تأخير التشغيل.
- الميزة مصممة لتكون "Shorebird-Safe"، حيث لا تعتمد على مكاتب توليد كود لسهولة التعديل السريع.
