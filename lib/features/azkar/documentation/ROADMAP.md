# 🗺️ Azkar Feature — Roadmap

---

# 🚀 Phase 1 — Core Azkar (MVP)

> **الهدف:** إطلاق أول نسخة عملية من ميزة الأذكار تتيح للمستخدم تصفح وقراءة جميع الأذكار الأساسية.

### Feature 1.1 — Categories

- عرض جميع أقسام الأذكار.
- ترتيب الأقسام.
- أيقونة لكل قسم.

### Feature 1.2 — Azkar List

- عرض جميع الأذكار داخل القسم.

### Feature 1.3 — Zikr Details

لكل ذكر:

- النص.
- عدد التكرارات.
- المصدر.
- درجة الحديث.
- فضل الذكر.

---

# 🚀 Phase 2 — Reading Experience

> **الهدف:** توفير تجربة قراءة مريحة وقابلة للتخصيص.

### Feature 2.1 — Reading Preferences

- تكبير الخط.
- تصغير الخط.
- تغيير نوع الخط.
- حفظ إعدادات القراءة.

### Feature 2.2 — Reading Session

- حفظ آخر مكان تمت قراءته.
- استكمال القراءة.
- منع إطفاء الشاشة أثناء القراءة.

### Feature 2.3 — Reading Information

- إظهار/إخفاء شرح الذكر.
- إظهار/إخفاء فضل الذكر.

---

# 🚀 Phase 3 — Counter

> **الهدف:** مساعدة المستخدم على تتبع عدد التكرارات بسهولة.

### Feature 3.1 — Counter

- عرض عدد التكرارات.
- عداد أثناء القراءة.
- إعادة تعيين العداد.

### Feature 3.2 — Counter Experience

- الاهتزاز عند العد.
- الانتقال التلقائي للذكر التالي.

---

# 🚀 Phase 4 — Search

> **الهدف:** الوصول السريع لأي ذكر.

### Feature 4.1 — Search

- البحث داخل جميع الأذكار.

### Feature 4.2 — Search Experience

- تمييز الكلمات المطابقة.
- سجل آخر عمليات البحث.

---

# 🚀 Phase 5 — Progress

> **الهدف:** حفظ تقدم المستخدم واستكمال القراءة بسهولة.

### Feature 5.1 — Reading Progress

- حفظ آخر ذكر تمت قراءته.
- حفظ آخر قسم تمت قراءته.
- نسبة الإنجاز داخل كل قسم.
- استكمال القراءة.

---

# 🚀 Phase 6 — Sharing

> **الهدف:** تسهيل مشاركة الأذكار مع الآخرين.

### Feature 6.1 — Copy

- نسخ الذكر.

### Feature 6.2 — Share

- مشاركة الذكر كنص.
- مشاركة الذكر كصورة.

---

# 🚀 Phase 7 — Notifications

> **الهدف:** تذكير المستخدم بالأذكار بشكل دوري.

### Feature 7.1 — Reminder Management

- تذكير يومي.
- أكثر من تذكير.
- اختيار وقت التذكير.
- تشغيل/إيقاف التذكيرات.

### Feature 7.2 — Notification Experience

- تخصيص رسالة الإشعار.
- فتح الذكر مباشرة من الإشعار.

---

# 🚀 Phase 8 — Accessibility

> **الهدف:** تحسين تجربة الاستخدام لجميع المستخدمين.

### Feature 8.1 — Accessibility

- دعم الخطوط الكبيرة.
- أزرار كبيرة.
- دعم قارئ الشاشة.

---

# 🚀 Phase 9 — Advanced Features

> **الهدف:** إضافة ميزات متقدمة لتحسين تجربة المستخدم.

### Feature 9.1 — Usage Intelligence

- عرض الأذكار الأكثر استخدامًا.
- عرض الأذكار الأكثر تكرارًا.

### Feature 9.2 — Reading Analytics

- سجل آخر الأذكار المقروءة.
- إحصائيات القراءة.

### Feature 9.3 — Smart Suggestions

- اقتراح ذكر حسب الوقت.
  - صباح.
  - مساء.
  - نوم.
  - وغيرها.
