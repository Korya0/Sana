# Teaching Prayer Feature (ميزة تعليم الصلاة)

توفر هذه الميزة دليلاً شاملاً وتفاعلياً لتعليم كيفية أداء الصلاة والوضوء، مع شرح مفصل لكل خطوة مدعوماً بالصور والنصوص الشرعية.

## المميزات التقنية
- **تحميل المحتوى**: يتم جلب بيانات تعليم الصلاة من ملف JSON محلي يحتوي على كافة الأقسام والخطوات.
- **التدرج في التعليم**: تقسيم المحتوى إلى أقسام منطقية (الوضوء، أركان الصلاة، السنن، إلخ).
- **دعم الوسائط**: ربط كل خطوة بصورة توضيحية لسهولة الفهم.
- **إدارة الحالة**: استخدام `TeachingPrayerCubit` لضمان تحميل المحتوى بسلاسة وعرض حالات الأخطاء.

## الهيكل المجلدات
- `data/datasources/`:
    - `teaching_prayer_local_data_source.dart`: المسؤول عن قراءة وتحليل ملف الـ JSON المحلي وتوفير البيانات للريبوزيتوري.
- `data/repositories/`:
    - `teaching_prayer_repository.dart`: يطبق واجهة `ITeachingPrayerRepository` لتوفير البيانات للطبقة العليا مع معالجة الأخطاء.
- `presentation/controller/`:
    - `teaching_prayer_cubit.dart`: يدير التفاعل بين الواجهة والبيانات.
- `presentation/views/`:
    - `teaching_prayer_view.dart`: الشاشة الرئيسية التي تعرض قائمة أقسام تعليم الصلاة.

## ملاحظات للمطورين
- تعتمد هذه الميزة على الأصول (Assets) الموجودة في `assets/data/teaching_prayer.json`.
- تم استخدام نظام `part/part of` لتنظيم الـ Cubit والـ State.
- تم فصل مصدر البيانات (LocalDataSource) لسهولة الاختبار وتطوير العملية مستقبلاً (مثل جلب البيانات من API).
