# Developer Dashboard Feature

## Overview
لوحة تحكم المطور (Developer Dashboard) هي ميزة إدارية داخل التطبيق تسمح للمسؤولين بمراقبة تفاعلات المستخدمين، وإدارة الملاحظات (Feedback)، والتحكم في بعض جوانب التطبيق الفنية دون الحاجة للدخول إلى Firebase Console مباشرة.

## Features
- **عرض الاقتراحات (Feedbacks):** عرض كافة الملحوظات والاقتراحات المرسلة من المستخدمين مرتبة تنازلياً حسب الوقت.
- **التفاصيل التقنية:** عرض معلومات جهاز المستخدم (نظام التشغيل، الموديل، إصدار التطبيق) لمساعدة المطور في تتبع المشاكل.
- **الحذف الذكي (Optimistic Deletion):** إمكانية حذف الاقتراحات مع تحديث فوري للواجهة (Optimistic UI) لضمان تجربة مستخدم سريعة.
- **المشاركة كصورة:** تحويل أي اقتراح إلى صورة مصممة بأناقة لمشاركتها مع فريق العمل أو على وسائل التواصل الاجتماعي، مع مراعاة خصوصية بيانات المستخدم التقنية في الصورة المشتركة.
- **الوصول الآمن (Secret PIN):** حماية اللوحة برمز سري (31903556) ومن خلال طريقة دخول مخفية (نقر مزدوج على نص "صدقة جارية" في الإعدادات).

## Project Structure (Clean Architecture)
- **Data Layer:**
  - `models/`: تحتوي على `DashboardFeedbackModel`.
  - `datasources/`: تتعامل مع Firestore لجلب وحذف البيانات.
  - `repositories/`: وسيط بين الـ Data Source والـ Presentation Layer مع معالجة الأخطاء.
- **Presentation Layer:**
  - `controller/`: إدارة الحالة باستخدام Bloc/Cubit (`DashboardCubit`).
  - `views/`: الشاشة الرئيسية للوحة التحكم.
  - `widgets/`: المكونات الفرعية (كروت الفيدباك، أزرار التحكم، شاشة المشاركة).

## Security
- الدخول محمي بـ `SecretPinDialog`.
- يتم حفظ الرمز السري حالياً برمجياً (Hardcoded) لسهولة الوصول السريع للمطور.
- البيانات التقنية تظهر فقط للمطور داخل الداشبورد وتختفي تلقائياً عند توليد صورة للمشاركة.
