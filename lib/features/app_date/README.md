# نظام مزامنة التاريخ الهجري

هذا النظام مصمم ليعطيك تحكماً كاملاً عبر **Firebase Remote Config**. إليك متى وكيف تستخدم كل متغير:

## 1. التعديل الصامت (`hijri_adjustment`)

- **متى تستخدمه؟** عندما تكون متأكداً 100% من خبر الرؤية في بلد معين (مثل مصر).
- **ماذا تفعل؟** تضع القيمة (1 أو -1) في Firebase.
- **النتيجة:** يتعدل التاريخ عند كل المستخدمين في هذا البلد "صمتاً" مع ظهور نبض ذهبي خفيف للتنبيه.

## 2. سؤال المستخدم (`enable_hijri_verification_dialog`)

- **متى تستخدمه؟** في ليلة الرؤية للشهور المهمة (رمضان والعيدين) لترك القرار النهائي للمستخدم.
- **ماذا تفعل؟** تجعلها `true` في بداية الشهر فقط، ثم أعدها `false` بعد يومين.
- **النتيجة:** يظهر دايلوج للمستخدم يسأله "هل التاريخ صحيح؟". إذا أكد المستخدم التاريخ مرة واحدة، لن يظهر له السؤال مجدداً طوال الشهر.

## 3. قائمة الشهور (`hijri_verification_months`)

- **متى تستخدمها؟** لتحديد الشهور التي يُسمح فيها بظهور سؤال المستخدم.
- **اقتراح:** اتركها دائماً `9,10,12` (رمضان، شوال، ذو الحجة).

---

### 📝 ملخص الواجهة (UI):

- **الضغط (Tap):** يفتح قائمة التعديل اليدوي للمستخدم في أي وقت.
- **التصميم:** مطابق لدايلوج "أذكار الخروج" الخاص بالتطبيق لضمان التناسق.
- **النبض:** إشارة بصرية أن التطبيق قام بالتصحيح تلقائياً.
