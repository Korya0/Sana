# 📅 App Date Feature (The Hijri Engine)

تعتبر ميزة **App Date** هي المحرك المركزي للوقت والتاريخ في تطبيق **سَـنَـا**. لا تكتفي الميزة بعرض التاريخ الهجري والميلادي فحسب، بل تعمل كـ **Source of Truth** لكافة الميزات الأخرى التي تعتمد على الوقت (مثل أوقات الصلاء، الأذكار المرتبطة باليوم، والمحتوى المتجدد).

## 🚀 المميزات الرئيسية
- **التوقيت المركزي:** تحديث تلقائي للتاريخ عند منتصف الليل لضمان دقة البيانات المعروضة.
- **التصحيح اليدوي (Hijri Adjustment):** إمكانية تعديل التاريخ الهجري بزيادة أو نقصان يوم ليتوافق مع رؤية الهلال في بلد المستخدم.
- **التحقق الشهري (Verification):** نظام ذكي يطلب من المستخدم التأكد من صحة التاريخ في الأشهر الحرم ورمضان (الأشهر التي تعتمد على الرؤية).
- **التكامل المعماري:** توفير تدفق (Stream) لكل أجزاء التطبيق لإعادة بناء الواجهات فور تغير التاريخ.

## 🏗 الهيكل المعماري (Refactored Clean Architecture)

تتبع الميزة معايير **SOLID** الصارمة مع مراعاة قيود **Shorebird** للتحديثات السريعة:

### 1. Data Layer
- **Model:** `AppDateValue` - يحمل التاريخ الميلادي والهجري وقيمة التعديل.
- **Repository:** `IAppDateRepository` - واجهة تجرد عملية تخزين واسترجاع البيانات (Adjustment).
- **Implementation:** `AppDateRepositoryImpl` - يتعامل مع `ISharedPref` للحفاظ على بيانات المستخدم.

### 2. Logic Layer (Cubit)
- **AppDateCubit:** يدير عمليات:
    - تهيئة الوقت عند تشغيل التطبيق.
    - جدولة التحديث التلقائي (`Timer`) عند منتصف الليل.
    - تنفيذ عمليات التصحيح (Adjustment).
- **AppDateState:** نظام حالات محمي (Sealed Classes):
    - `AppDateInitial`: الحالة الأولى قبل التحميل.
    - `AppDateLoaded`: الحالة النشطة التي تحمل البيانات.

### 3. Presentation Layer (UI)
- **Widgets:**
    - `HijriAndGregorianDateWidget`: الودجت الرئيسي للعرض (يستخدمه الـ AppBar غالباً).
    - `HijriAdjustmentBottomSheet`: واجهة اختيار فرق الأيام.

## 🛠 التكامل مع الميزات الأخرى (Bridge Pattern)
تعتمد ميزات مثل `DailyContentCubit` و `PrayerTimesCubit` على هذا الـ Cubit بشكل أساسي. يتم قراءة التاريخ عبر:
```dart
final now = (appDateCubit.state as AppDateLoaded).date.gregorian;
```
*(ملاحظة: تم إضافة Bridge Getters لضمان التوافق مع الكود القديم دون حدوث Crash).*

## 🎨 رموز التصميم (Design Tokens)
- **Colors:** تعتمد على `AppColors.gold` و `AppColors.textPrimary`.
- **Spacing:** تستخدم نظام `AppSpacing` الموحد (v4, v12, v24) لضمان تناسق الواجهة.
- **Typography:** تعتمد على خط **Cairo** للأرقام والميلادي، ونظام تنسيق خاص للهجري.

## 📝 ملاحظات للمطورين
- عند إضافة أي ميزة تعتمد على "اليوم الحالي"، يجب حقن `AppDateCubit` والاستماع لـ `Stream` الخاص به بدلاً من الاعتماد على `DateTime.now()` مباشرة، لضمان استجابة الميزة للتحديث التلقائي عند منتصف الليل.
- الميزة مهيأة للتحول الكامل إلى `@freezed` في التحديثات الكبيرة القادمة.
