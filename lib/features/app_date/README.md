# 📅 App Date Feature (نظام التاريخ الذكي)

هذه الميزة هي "ساعة القلب" في التطبيق، المسؤولة عن إدارة وعرض التاريخين **الهجري والميلادي** بدقة عالية وبشكل محلي بالكامل، مع ضمان التحديث التلقائي والتفاعل مع المناسبات الإسلامية الكبرى.

## 🌟 المميزات الرئيسية

1.  **المزامنة الثنائية**: عرض متزامن للتاريخ الميلادي والهجري بتنسيق عربي أصيل.
2.  **التعديل اليدوي الذكي**: إمكانية تصحيح التاريخ الهجري (`+1` أو `-1`) ليتوافق مع رؤية الهلال في بلدك، مع حفظ الخيار تلقائياً.
3.  **التنبيه الشهري (Moon Sighting)**: تفعيل آلية التأكد الاجتماعي في بداية الأشهر الكبرى (رمضان، شوال، ذو الحجة) لضمان دقة العبادات.
4.  **تحديث منتصف الليل**: نظام آلي يقوم بتحديث التاريخ فور حلول الساعة 12:00 صباحاً دون الحاجة لإعادة تشغيل التطبيق.

---

## 🛠️ كيف تعمل الميزة؟

-   **Persistence**: يتم تخزين التعديلات الهجرية وآخر شهر تم التحقق منه باستخدام `SharedPref`.
-   **Logic**: يعتمد الحساب الهجري على مكتبة `hijri_calendar` مع دمج منطق التعديل (`adjustment`) داخلياً في موديل `AppDateValue`.
-   **State Management**: يستخدم `AppDateCubit` لإدارة دورة حياة التاريخ، بما في ذلك الـ Timers الخاصة بتحديث منتصف الليل.

---

## 📂 مكونات الميزة (Architecture)

### 1️⃣ الطبقة المنطقية (Logic Layer)
-   `AppDateValue`: الموديل المسؤول عن تحويل وحمل البيانات التاريخية.
-   `AppDateCubit`: المحرك المسؤول عن إدارة الوقت، التخزين، وإظهار نوافذ التأكيد.

### 2️⃣ واجهة المستخدم (UI Layer)
| الـ Widget | الوظيفة |
| :--- | :--- |
| `HijriAndGregorianDateWidget` | المكون الرئيسي في الشاشة الرئيسية الذي يعرض الوقت ويراقب التغييرات. |
| `HijriAdjustmentBottomSheet` | واجهة تعديل التاريخ اليدوي بتصميم "سلس". |
| `HijriSocialVerificationDialog` | نافذة التأكيد التي تظهر في الأشهر الهجرية الحاسمة. |

---

## 📝 ملاحظات للمطور
*   **Monthly Verification**: يتم تفعيل نافذة التأكيد في الأشهر [9، 10، 12] فقط لمرة واحدة في الشهر.
*   **Testing**: يمكن اختبار تحديث منتصف الليل عبر تقليل مدة الـ Timer في الكود يدوياً.
*   **Formatting**: نستخدم `AppDateFormatter` (موجود في الـ core) لضمان توحيد شكل التاريخ في كل التطبيق.
