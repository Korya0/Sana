# Splash Feature (شاشة البداية)

هي أول شاشة تظهر للمستخدم عند فتح التطبيق، وتعمل كبوابة للدخول مع ضمان جاهزية الإعدادات الأساسية.

## الوظائف الأساسية
- **التحقق من الصلاحيات**: استخدام `LocationGuard` للتأكد من تفعيل خدمات الموقع كشرط أساسي لعمل ميزات التطبيق (مواقيت الصلاة، القبلة).
- **التوجيه الذكي**: بعد التحقق من الصلاحيات، يتم توجيه المستخدم تلقائياً إلى الشاشة الرئيسية (Home).
- **الهوية البصرية**: عرض شعار التطبيق (Logo) واسم التطبيق بأسلوب أنيق مع أنيميشن Fade In.

## الهيكل المجلدات
- `presentation/views/`:
    - `splash_view.dart`: الشاشة الرئيسية التي تحتوي على منطق التحقق والتوجيه.
- `presentation/widgets/`:
    - `splash_logo_and_name.dart`: المكون البصري الذي يعرض الشعار والاسم.

## ملاحظات للمطورين
- تعتمد الشاشة بشكل كبير على `LocationGuard` لضمان تجربة مستخدم خالية من أخطاء فقدان الموقع الجغرافي.
- تم استخدام `AppAnimations` لتوفير دخول سلس للعناصر البصرية.
