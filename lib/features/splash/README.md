# 🌊 ميزة شاشة البداية (Splash Feature)

## 📌 نظرة عامة
تمثل الشاشة الأولى التي تظهر للمستخدم. كانت تعاني من سوء إدارة التنقل، والاعتماد على توقيت مباشر (`Future.delayed`) متداخل داخل الواجهة بالإضافة لخلط منطق صلاحيات الموقع (`LocationGuard`) داخل شاشة البداية.

## 🏗 البنية المعمارية (Clean Architecture)

- **Presentation Layer**:
  - **الكيوبيت (SplashCubit)**: تم إنشاء كيوبيت خاص للـ Splash للتعامل مع محاكاة التهيئة المبدئية للتطبيق (سواء كان توقيت زمني كنوع من الأنميشن، أو استدعاءات API مستقبلية) بحيث يرسل حالة `SplashFinished` لتقوم الشاشة بالتوجيه.
  - **الواجهة (SplashView)**: تم إزالة `LocationGuard` لمنع طلب الصلاحيات بشكل خاطئ قبل وصول المستخدم للشاشة الرئيسية، وتم تحويل التوجيه ليصبح نظيفًا وتفاعليًا (Reactive) بناءً على مستمعات Bloc (`BlocListener`).

## ⚡️ أبرز التحسينات
- إزالة الاعتماد المباشر على التوقيت و `StatefulWidget` مع `initState`.
- فصل منطق إدارة الموقع وجعل الواجهة نظيفة ومخصصة فقط لشاشة البداية.
