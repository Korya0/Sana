# 📅 Daily Content Feature (المحتوى اليومي)

هذا الموديول مسؤول عن إدارة وعرض المحتوى المتجدد يومياً في التطبيق، بما في ذلك "حديث اليوم"، "سنة مهجورة"، و"اسم الله الحسنى لليوم"، مع نظام ذكي لضمان تنوع المحتوى وعدم تكراره.

## 🛠️ كيف تعمل الميزة؟

1.  **المحتوى المختلط**: يجمع الموديول بين ثلاثة أنواع من المحتوى:
    *   **أحاديث نبوية**: مختارة بعناية من ملف JSON محلي.
    *   **سنن مهجورة**: لتشجيع المستخدم على إحياء سنن النبي ﷺ.
    *   **أسماء الله الحسنى**: يتم اختيار اسم مختلف كل 24 ساعة.
2.  **نظام التقدم والاشتقاق (Shuffled Sequence)**:
    *   لضمان عدم تكرار المحتوى، يتم توليد قائمة عشوائية مرتبة (Shuffled Indices) لكل نوع من المحتوى وتحفظ محلياً.
    *   يتم التقدم في هذه القائمة يوماً بيوم. عند انتهاء كل الأحاديث أو السنن، يتم إعادة ترتيب القائمة عشوائياً والبدء من جديد.
3.  **المزامنة مع التاريخ**:
    *   يعتمد الموديول على `AppDateCubit` لمعرفة حالة التغيير في اليوم.
    *   إذا فتح المستخدم التطبيق في يوم جديد، يتم تلقائياً الانتقال للمحتوى التالي.
4.  **نظام المفضلة (Favorites System)**:
    *   يمكن للمستخدم حفظ أي حديث أو سنة في قائمة المفضلة للرجوع إليها لاحقاً، وتُحفظ هذه البيانات محلياً عبر `SharedPreferences`.
5.  **المشاركة والملصقات الفنية**:
    *   يدعم الموديول تحويل الحديث أو السنة إلى "لوحة فنية" (Premium Poster) بنفس أسلوب كروت القرآن لتعزيز جودة المحتوى المشارك على وسائل التواصل.

---

## ✨ المميزات التقنية (Technical Features)

-   **كفاءة الذاكرة (Memory Caching)**:
    *   تم تحسين الموديول لعمل كاش للبيانات المفضلة والمحتوى المقروء من JSON لتجنب استهلاك موارد المعالج والبطارية في عمليات القراءة المتكررة.
-   **إدارة الحالة المستمرة**:
    *   يستخدم `DailyContentRepository` منطقاً معقداً لإدارة عدة حالات في وقت واحد (Viewed Status, Current Index, Shuffled Indices) لضمان عدم ضياع تقدم المستخدم حتى عند غلق التطبيق.
-   **الاستجابة للوقت (AppDate-Aware)**:
    *   الموديول مربوط بنظام التاريخ العالمي للتطبيق، مما يجعله قادراً على تحديث المحتوى لحظة دخول اليوم الجديد دون الحاجة لإعادة تشغيل التطبيق.

---

## 📂 هيكل الملفات (Structure)

-   `data/datasource/daily_content_datasource.dart`: إدارة جلب البيانات من Assets مع آلية كاش داخلية.
-   `data/models/daily_content_model.dart`: نموذج بيانات المحتوى (نص، عنوان، مصدر).
-   `data/repositories/daily_content_repository.dart`: محرك المنطق؛ إدارة القوائم العشوائية، تتبع الفهارس (Indices)، وإدارة المفضلة.
-   `presentation/controller/`:
    -   `daily_content_cubit.dart`: التنسيق بين الوقت والبيانات وتحديث الواجهة.
    -   `daily_content_state.dart`: الحالة الكاملة للمحتوى اليومي (النوع، الحالة، المفضلة).
-   `presentation/views/daily_content_favorites_view.dart`: صفحة عرض المحتوى الذي تم حفظه.
-   `presentation/widgets/`: تحتوي على الـ Dialogs وكروت المشاركة الفنية.

---

## 📝 ملاحظات للمطور
*   **Indices Management**: يتم حفظ ترتيب العناصر العشوائي في الشيرد بريف بنفس الطول الأصلي للقائمة. إذا قمت بتغيير محتوى ملف JSON (إضافة عناصر جديدة)، يفضل مسح الداتا أو عمل `reshuffle` برمجياً.
*   **Favorites Performance**: يتم تحميل المفضلة في الذاكرة عند تشغيل التطبيق لضمان سرعة التحقق (`isFavorite`) عند التنقل بين المحتويات.
